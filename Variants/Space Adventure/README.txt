SPACE ADVENTURE

An example variant created for X-opoly, with newly authored fictional place
names and seven piece designs generated from original prompts.

SELECT
Banker: House rules > Customize properties > Game variant > Space Adventure.
Apply before gameplay starts. The seven custom pieces appear first; all classic
pieces remain available. Selecting an example never changes an existing game
until the banker applies it.

THE BOARD
22 streets explore outposts, icy settlements, botanical labs, shipyards,
canyons, markets, gardens, and grand orbital destinations.
Four shuttleports use railroad rules. Daybeam Power Array and Icewell Water
Plant use utility rules. All numeric values match the classic property CSV.
The ordinary tax names and amounts are unchanged.

THE PIECES
Rocket: a retro rocket ship with a porthole, fins, and exhaust flame.
Comet: a rocky head with a long sweeping tail.
Planet: a striped planet with a prominent tilted ring.
Ray-gun: a playful retro science-fiction ray gun.
Little Green Man: a full-body alien, rendered in black and white.
Astronaut: a full-body explorer in a spacesuit.
Robot: a full-body robot with jointed limbs.

MAKE YOUR OWN VARIANT
Copy this folder and rename it. Edit only the names or values you want in
properties.csv, preserving its headers and unique IDs. Replace the PNGs with
your own transparent images under 5 MB each. PNG filenames become piece names.
Remove unused PNGs; keep them directly in the variant folder.
Refresh the app to discover your variant; the banker can then select it.

ARTWORK
Seven black-and-white piece icons generated using the built-in OpenAI image
generation tool. No existing character artwork was supplied as a reference.
The generation prompts are recorded in ART-PROMPTS.json.
